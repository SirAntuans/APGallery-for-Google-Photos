> ¿Qué es?

APGallery conecta tu cuenta de Google con WordPress mediante la Google Photos Picker API y te deja elegir qué fotos compartir desde el selector oficial de Google. Las fotos se importan a tu biblioteca de medios y se muestran en una galería responsive con lightbox.

// Google eliminó el 31/03/2025 los scopes de la antigua Library API.

// La Picker API es la única vía oficial actual para acceder a las fotos del usuario.

captura_01: resultado final de la galería en tu sitio

Características

  • Selector oficial de Google Photos: eliges tú qué compartir
  • Fotos servidas desde tu hosting (las URLs de Google expiran; los adjuntos locales no)
  • Grid responsive 1-6 columnas + lightbox integrado
  • Refresh token cifrado (AES-256-CBC + HMAC) y refresco automático de tokens
  • Detección de duplicados y validación de scope OAuth

> Configuración de la cuenta de Google

# Solo se hace una vez. Necesitas: una cuenta de Google sin Protección Avanzada.

1 Crear el proyecto

  1. Entra en Google Cloud Console
  2. Selector de proyectos → Nuevo proyecto → nómbralo (p. ej. APGallery) → Crear

2 Habilitar la API

  1. APIs & Services → Library
  2. Busca Google Photos Picker API → Habilitar

! Solo esta API. La "Photos Library API" ya no sirve para acceder a la biblioteca del usuario.

captura_02: Library → Google Photos Picker API → Enable

3 OAuth consent screen

  1. APIs & Services → OAuth consent screen → tipo External
  2. Nombre de app y email de soporte
  3. Test users: añade el email de la cuenta que conectarás (¡paso crítico! sin esto Google bloquea el acceso)
captura_03: consent screen → test users

4 Credenciales OAuth 2.0

  1. APIs & Services → Credentials → Create credentials → OAuth client ID
  2. Tipo: Web application
  3. En Authorized redirect URIs añade la URL exacta que muestra el plugin:
https://TU-DOMINIO.com/wp-admin/admin-post.php?action=apgallery_oauth_callback
  • Copia Client ID y Client Secret
    • captura_04: OAuth client → redirect URI

    > Conectar en WordPress

    1 Instalar y activar

    Plugins → Añadir nuevo → Subir plugin → sube el ZIP de la release → Activar.

    2 Credenciales

    Ajustes → APGallery Google Photos → pega Client ID y Client Secret → Guardar credenciales.

    captura_05: panel de ajustes con credenciales

    3 Conectar la cuenta

    Conectar con Google Photos → inicia sesión con la cuenta (la del test user) → acepta el consentimiento.

    // tip: usa ventana de incógnito si tienes varias sesiones de Google abiertas.

    4 Elegir y sincronizar fotos

    1. Pulsa Elegir fotos de Google Photos → se abre el selector de Google
    2. Marca las fotos (puedes navegar por álbumes) → Hecho
    3. Vuelve al panel → Sincronizar fotos seleccionadas
    4. Listo: las fotos quedan en tu biblioteca de medios

    > Uso: el shortcode

    Añádelo en cualquier página o entrada:

    [apgallery] [apgallery columns="4"] // grid de 4 columnas (1-6, por defecto 3)
    • columns — columnas del grid (1-6). En móvil pasa automáticamente a 2.
    • Lightbox integrado: clic en la foto para verla en grande, Esc o clic fuera para cerrar.
    • Para añadir más fotos más adelante: repetir "Elegir fotos" → "Sincronizar".

    > Errores conocidos

    SíntomaCausaSolución
    Error 400: policy_enforced
    "Protección Avanzada no ha aprobado…"    		 La cuenta está en el Programa de Protección Avanzada, que bloquea apps no verificadas Usa otra cuenta sin Protección Avanzada (compartiéndole las fotos desde la protegida)
    redirect_uri_mismatch La URI de redirección de Google Cloud no coincide con la del plugin Copia la URL exacta que muestra el panel (https, sin barras finales)
    "Google no concedió el permiso de la Picker API…" La Picker API no está habilitada o el token nació sin scope Habilita la Picker API, revoca la app en myaccount.google.com/permissions y reconecta
    (foto.jpg) Forbidden Versiones ≤ 0.6.1 descargaban sin header Authorization Actualiza a ≥ 0.6.2 (v1.0.1 actual)
    "Request had insufficient authentication scopes" Uso de la Library API con scopes retirados por Google (31/03/2025) Este plugin ≥ 0.6.0 ya usa la Picker API; actualiza
    El token deja de funcionar a los ~7 días App en modo Testing: los refresh tokens de test caducan semanalmente Reconecta la cuenta (o publica/verifica la app en Google Cloud para tokens permanentes)
    No aparece la cuenta correcta en la pantalla de Google Sesión de navegador con otra cuenta activa Incógnito o cerrar las demás sesiones de Google
